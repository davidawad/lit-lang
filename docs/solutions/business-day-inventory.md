## Findings

**Flagged uses: 17.** These select a counting rule whose pack calendar closes federal holidays but either has an empty `district-state-holidays` placeholder or lists state holidays only for forward extension. FRCP 6(a)(6)(C), FRBP 9006(a)(6)(C), and FRCrimP 45(a)(6)(C) define a legal holiday to include a day declared a holiday by the state where the district court is located. The calendar's open-day set can therefore count an intermediate state holiday as open even though the governing computation rule treats it as a legal holiday. This flags a rule/calendar mismatch for PM triage; it does not establish which individual state holiday dates affect a particular deadline. The state holiday text and court-specific closure orders must be checked for each flagged court.
