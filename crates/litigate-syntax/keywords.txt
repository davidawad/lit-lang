# The contextual keywords of litigate (SPEC §2): the one hand-edited list.
# One per line: `Variant text highlight`. `crates/litigate-syntax/build.rs`
# generates `SyntaxKind`'s keyword variants from it, and `just
# editor-queries` (run by `just tree-sitter-generate` and `just lit-sync`)
# every editor keyword list: `tree-sitter-litigate/queries/highlights.scm`
# (from `queries/highlights.scm.in`), Helix's copy of it and
# `emacs/litigate-ts-mode-keywords.el`.
#
# highlight: declaration (opens a declaration), clause (clause and field
# keywords), test (test statements), conditional, directive, or none (a
# keyword the grammar highlights as a named node, or not at all).
#
# `.gitattributes` merges this file with `union`, so two branches adding
# different keywords never conflict; order is free. Add the keyword to the
# tree-sitter grammar too (`tests/conformance.rs` keeps the sets equal).
